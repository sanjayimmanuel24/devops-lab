# Results

Every `run.ps1` saves its full terminal output here as `<experiment>_<date-time>.txt`.

After a successful rehearsal on your laptop, also drop screenshots here (browser pages, GitHub Actions run,
Docker Hub, Jenkins build page, `kubectl get` output). Then commit and push:

```powershell
git add results
git commit -m "Lab outputs"
git push
```

They're then on GitHub, so you can open them from any machine as a backup.
